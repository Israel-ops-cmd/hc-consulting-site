# HC Consulting · Landing page

React + Vite + Tailwind CSS v4 + Framer Motion.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # gera a pasta dist/
```

- Textos, telefone, serviços, depoimentos e FAQ: `src/data/site.js`
- Cores e fontes da marca: bloco `@theme` em `src/index.css`
- SEO, Open Graph e dados estruturados: `index.html`
- Imagem de compartilhamento (WhatsApp/redes): `public/og-image.png`
- Deploy: `vercel.json` já configurado para Vite.
